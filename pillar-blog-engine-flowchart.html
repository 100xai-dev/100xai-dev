One engine. every client.
The pillar-blog flow, mapped.

A live map of how a single seed keyword becomes a published-ready article. Three pipelines, one shared job state. The generic engine never changes — only the ClientProfile does. Every node tagged reads ClientProfile is a place a new client plugs in.

The state machine

A job moves through four states, one pipeline per hop.

The stage field is the entire orchestration mechanism. Each pipeline picks up jobs the previous one advanced — fully decoupled.

The golden rule

Two layers. Only one ever changes per client.

Onboarding a client = create one ClientProfile record. If anyone ever edits a prompt inside a pipeline step to onboard a client, that string was missed during templating — treat it as a bug.
